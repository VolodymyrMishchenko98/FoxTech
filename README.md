# FoxTech

Маркетплейс сучасної техніки на Django + Tailwind CSS з динамічним кошиком, промокодами, міні-грою та рольовим чатом підтримки (клієнт ↔ менеджер).

## Можливості

- Каталог товарів з фільтрами та пошуком
- Детальна сторінка товару
- Авторизація та реєстрація користувачів з вибором ролі (`user` / `manager`)
- Адмінпанель для управління товарами, категоріями та користувачами
- Динамічний кошик (для авторизованих і гостей через session)
- Промокоди з перерахунком суми кошика
- Міні-гра з бонусами
- Чат підтримки: клієнт ↔ менеджер, real-time оновлення, вхідні для менеджера
- Адаптивний дизайн з підтримкою української мови
- Кешування категорій, lazy loading, оптимізована завантаження сторінок

## Технології

- Python 3.13+
- Django 6.x
- Tailwind CSS 3 (через CDN)
- SQLite (розробка) / PostgreSQL (продакшн)
- WhiteNoise
- dj-database-url
- Чистий JS + `fetch` для динамічних частин (кошик, чат) — без DRF

## Вимоги

- Python 3.10+
- pip
- Віртуальне середовище (рекомендується)

## Швидкий старт

```bash
git clone https://github.com/VolodymyrMishchenko98/FoxTech.git
cd FoxTech/foxtech

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python manage.py migrate
python manage.py createsuperuser   # опціонально
python manage.py runserver
```

Відкрийте http://127.0.0.1:8000/

## Змінні середовища

- `SECRET_KEY` — обов'язково задайте в продакшені. У `settings.py` є небезпечний запасний варіант (`django-insecure-...`), який НЕ слід використовувати публічно.
- `DEBUG` — `True` для розробки, `False` для продакшену.
- `ALLOWED_HOSTS` — налаштуйте під свій домен/хост.
- `DATABASE_URL` — для продакшену (наприклад, PostgreSQL на Render/Railway).

> **Важливо:** паролі в Django хешуються з використанням `SECRET_KEY`. Якщо на локальній машині і на продакшені стоять різні `SECRET_KEY`, суперкористувача, створеного локально, не можна буде увійти на сайті («неправильний пароль»). У такому випадку створіть суперкористувача прямо на продакшені: `python manage.py createsuperuser` (наприклад, через Render Shell / SSH). Ніколи не змінюйте `SECRET_KEY` на продакшені, якщо вже є користувачі — їх паролі доведеться пересоздавати.

## Структура проєкту

```
foxtech/
  foxtech/           - налаштування проекту (settings, urls, wsgi)
  store/             - додаток каталогу товарів, кошик, промокоди, міні-гра
  accounts/          - додаток авторизації, профілів, ролей
  chat/              - додаток чату (треди, повідомлення, вхідні для менеджера)
  templates/         - шаблони HTML
  static/            - статичні файли (CSS, JS, зображення)
  media/             - завантажені користувачами файли
  requirements.txt   - залежності Python
```
